### 任务1: 实现移动端独立 Banner 功能

用户反馈网站首页的 banner 在电脑端显示良好，但在手机上会被裁剪到只剩下中间一小部分。用户希望为移动端单独设置窄版本的 banner，以优化显示效果。

#### 分析过程:
1. 分析了项目结构和 banner 实现方式
2. 查看了 `src/config.ts` 中的 banner 配置
3. 查看了 `src/layouts/MainGridLayout.astro` 中的 banner 渲染逻辑
4. 查看了 `src/layouts/Layout.astro` 中的 banner JavaScript 代码
5. 查看了 `src/types/config.ts` 中的类型定义

#### 实施方案:

**步骤1: 修改类型定义**
- 文件: `src/types/config.ts`
- 在 `SiteConfig.banner` 类型中添加 `mobileSrc?: string` 字段
- 目的: 为移动端 banner 提供类型支持

**步骤2: 更新配置文件**
- 文件: `src/config.ts`
- 在 `siteConfig.banner` 配置中添加 `mobileSrc: "assets/images/banner-mobile.jpg"`
- 目的: 配置移动端 banner 图片路径

**步骤3: 修改布局组件**
- 文件: `src/layouts/MainGridLayout.astro`
- 实现响应式 banner 切换:
  - 桌面端 (≥768px): 显示 `banner-desktop`，使用 `siteConfig.banner.src`
  - 移动端 (<768px): 显示 `banner-mobile`，使用 `siteConfig.banner.mobileSrc`
  - 使用 Tailwind 的响应式类 (`hidden md:block` 和 `md:hidden`) 控制显示
  - 添加回退逻辑: 如果未配置 mobileSrc，则使用桌面版 banner

**步骤4: 更新 JavaScript 代码**
- 文件: `src/layouts/Layout.astro`
- 修改 `showBanner()` 函数:
  - 原逻辑: 通过 `document.getElementById('banner')` 获取单个 banner 元素
  - 新逻辑: 通过 `document.querySelectorAll('[id^="banner"]')` 获取所有 banner 元素
  - 为每个 banner 元素移除 `opacity-0` 和 `scale-105` 类
  - 目的: 支持多个 banner 元素的动画效果

#### 技术实现细节:

**配置示例:**
```typescript
banner: {
    enable: true,
    src: "assets/images/banner.jpg",              // 桌面版 banner
    mobileSrc: "assets/images/banner-mobile.jpg", // 移动端 banner
    position: "center",
    credit: {
        enable: true,
        text: "じゃが / 恋文と１３歳の女優",
        url: "https://jagaricoot.fanbox.cc/"
    }
}
```

**响应式实现:**
```astro
<!-- 桌面版 banner -->
<ImageWrapper id="banner-desktop" 
    class:list={["hidden md:block object-cover h-full transition duration-700 opacity-0 scale-105"]}
    src={siteConfig.banner.src} 
/>

<!-- 移动端 banner -->
<ImageWrapper id="banner-mobile" 
    class:list={["md:hidden object-cover h-full transition duration-700 opacity-0 scale-105"]}
    src={siteConfig.banner.mobileSrc} 
/>
```

**修改的文件:**
1. `src/types/config.ts` - 添加 mobileSrc 类型定义
2. `src/config.ts` - 添加移动端 banner 配置
3. `src/layouts/MainGridLayout.astro` - 实现响应式 banner 切换
4. `src/layouts/Layout.astro` - 更新 showBanner 函数支持多个 banner

#### 测试验证:
- 运行 `pnpm check` 进行 TypeScript 类型检查，无错误
- 启动开发服务器测试功能
- 验证桌面端和移动端分别显示不同的 banner

#### 最终效果:
- 桌面端显示宽版 banner (`banner.jpg`)
- 移动端显示窄版 banner (`banner-mobile.jpg`)
- 无配置的移动端自动回退到桌面版 banner
- 两个 banner 都能正确应用过渡动画效果
